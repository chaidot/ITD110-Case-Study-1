# Barangay Profiling System

A full-stack web application developed as an ITD110 case study for managing and presenting barangay profiling information.

The project demonstrates frontend and backend development, authentication, data management, API development, and data visualization using a modern JavaScript stack.

## 🚀 Features

- Full-stack web application architecture
- Barangay profiling and data management
- CRUD operations
- User authentication and authorization
- JWT-based authentication
- Password hashing
- Input validation
- Data visualization and charts
- CSV data processing
- File upload handling
- Responsive user interface
